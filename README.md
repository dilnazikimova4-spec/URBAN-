
# PACMAN - URBAN NEON

## Описание игры
Pacman - Urban Neon — аркадная игра на Python.
Игрок должен собрать все точки и золотые монеты,
избежать призраков и найти выход из лабиринта.

## Технологии
- Python 3
- Tkinter
- ООП

## Запуск игры
Откройте терминал в папке проекта и напишите:

python main.py

## Управление
- Стрелка вверх — движение вверх.
- Стрелка вниз — движение вниз.
- Стрелка влево — движение влево.
- Стрелка вправо — движение вправо.
- R — перезапуск игры.

## Дополнительные возможности
- Супер-сила на 5 секунд.
- Быстрый оранжевый призрак.
- Неоновое оформление.
- Золотые монеты (+50 очков).
- Съеденные призраки (+200 очков).
- Система жизней.
- Условия победы и поражения.

## Классы
- GameObject — родительский класс объектов.
- Character — родительский класс персонажей.
- Player — игрок.
- Ghost — обычный призрак.
- FastGhost — быстрый призрак.
- Wall — стена.
- Dot — точка.
- Coin — золотая монета.
- PowerPellet — супер-сила.
- Exit — выход.
- Maze — лабиринт.
- Game — управление игрой.

## Наследование
Player и Ghost наследуются от Character.
FastGhost наследуется от Ghost.
Character, Wall, Dot, Coin, PowerPellet и Exit
используют GameObject как родительский класс.

Используются super(), переопределение методов
и полиморфизм.

## Участники проекта
- Дильназ — Game.
- Бану — Maze, Wall, Exit.
- Даниал — Character, Player, Ghost.
